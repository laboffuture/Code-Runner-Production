Key Data Flows
🐍 Code Execution Flow
Student writes Python code in Monaco Editor on /problems/:id
Frontend POST /execution/submit → API (Nginx → api-1 or api-2)
API validates JWT, creates BullMQ job in code-execution queue (Redis)
API returns jobId instantly to frontend
Frontend polls GET /execution/:jobId every 500ms
runner-1 or runner-2 picks up job from Redis queue
Runner pulls pre-warmed Python container from pool (min 2, max 5 containers)
Code executes in sandboxed Docker container (5s timeout, no network)
Output captured → container returned to pool or recycled after 30 min
Result saved to ExecutionResult collection, job status updated in Redis
Frontend poll receives completed result, shows output/errors
🔐 Authentication Flow
POST /auth/login with email + password
bcrypt compares password against hash in DB
JWT signed with secret, returned to client
Token stored in localStorage via AuthContext
Every request includes Authorization: Bearer <token>
auth.middleware.ts verifies token on every protected route
🖼 Flowchart Image Flow
Frontend loads /sessions/:id/introduction
Fetches session via /api/sessions/:id → backend
Looks up SESSION_FLOWCHART_CONFIG[level][session]
getFlowchartUrl() builds Cloudinary CDN URL
Images served with f_auto,q_auto optimization
Per-flow title + explanation from FlowConfig data
